# IBM XGA Projects and Research

This directory contains a working DOS graphics demo, exploratory research, historical project plans, and third-party reference material.

## Current Project

The active, runnable project is [Dreams XGA-demo](xga-demo/README.md). Its README is the source of truth for builds, controls, emulator setup, and what has actually been tested. The tested first release is preserved in `xga-demo/versions/v1/`; version 2 is the development copy.

## Research and Reference Notes

- [XGA acceleration targets and demo ideas](XGA-ACCELERATION-TARGETS-AND-DEMO-IDEAS.md): general accelerator capabilities and possible workloads; ideas and performance estimates are not benchmark results.
- [SCI2 and XGA research notes](SCI2-XGA-RESEARCH-NOTES.md): exploratory notes; the proposed SCI2 integration path has not been verified.
- [Downloaded demo source assessment](DOWNLOADED-DEMO-SOURCES-ANALYSIS.md): a historical survey of source packages and possible ports.
- [Hornet demo porting study](HORNET-DEMO-PORTING-STUDY.md): a historical assessment of possible effects and porting ideas.
