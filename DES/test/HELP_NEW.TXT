DES 1.3 - Description Enhanced System

By Dag Erik Hages‘ter / Retro Erik using Codex in VS Code

Lists files and directories with descriptions from DESCRIPT.ION.
Uses ColorDir colors when COLORDIR is set in AUTOEXEC.BAT.

DESCRIPT.ION has one description per file, for example:
  MONKEY.EXE Monkey Island  1990 EGA/VGA/ADLIB

4DOS ColorDir uses COLORDIR to select colors by directory or extension.
  SET ColorDir=dirs:bri mag; zip arj:bri blu; com exe:bri gre; bat: bri red; gif  jpg png:yel; txt me now:gre

DES reads DESCRIPT.ION and COLORDIR itself; 4DOS is not required.

To list one screen at a time use /P (just like DIR).
In this mode, DES scrolls descriptions too long for the screen.
To pause horizontal scrolling, use the PAUSE key on the keyboard.

Usage: DES [drive:][path\pattern] [/P] [/A] [/I]
       DES D: or DES D:\GAMES  List a drive or directory
       DES /A           Include hidden (H) and system (S) entries
       DES /I           Show drive kind and file system
       DES /? or DES /H   Show this help
